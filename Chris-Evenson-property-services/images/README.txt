TIPS
  - Use .jpg files with these exact names (convert PNG/HEIC to JPG first).
  - Download real photos from Google Photos via the three-dot menu >
    Download (NOT "Save page as", which saves a web page).
  - Aim for ~1200-1600 px on the long side, under ~500 KB each.
